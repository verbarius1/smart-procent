# Смарт-процент — прототип лендинга

Прототип одностраничного лендинга ЦФА «Смарт-процент» (эмитент — АО «ТБанк») для согласования. Это не официальная страница Т‑Банка: поисковики её не индексируют, а на странице стоит пометка «Прототип».

## Файлы

- `index.html` — страница целиком: вёрстка, стили и скрипт.
- `series.json` — выпуски, которые показываются на странице.
- `robots.txt` — запрет индексации.

## Как обновить выпуски

Отредактируйте `series.json`. Для каждого выпуска укажите:

| Поле | Пример | Что это |
| --- | --- | --- |
| `name` | Смарт-процент До 02 февраля | Название, как в приложении |
| `rate` | 13.5 | Ставка, % годовых |
| `termLabel` | 4 месяца | Срок словами |
| `placementDate` | 2026-10-05 | Дата размещения |
| `maturityDate` | 2027-02-02 | Дата погашения |
| `collectionStart` | 2026-09-28 | Начало сбора (необязательно, нужно для прогресс-бара) |
| `collectionEnd` | 2026-10-05 | Окончание сбора |
| `minAmount`, `price` | 1000 | Минимальное участие и цена одного ЦФА, ₽ |
| `fee` | 0% | Комиссия за размещение |
| `url` | https://www.tinkoff.ru/invest/shelves/issuance/dfa/… | Страница выпуска в Т‑Инвестициях |

Выпуски с закрытым сбором (по московскому времени) скрываются автоматически. Чтобы посмотреть макет с закрытым выпуском, добавьте к адресу `?preview`.

Те же данные продублированы внутри `index.html` (блок `series-data`): они используются, когда страница открыта как файл. Обновляйте оба места.

## Настройки

В начале скрипта в `index.html` есть объект `CONFIG`. Пустая строка — блок или ссылка на странице скрыты.

- `SHELF_URL` — все выпуски Смарт-процента в Т‑Инвестициях
- `PRESENTATION_URL`, `RISKS_URL`, `ISSUE_DOCS_URL` — документы
- `AD_LABEL` — маркировка рекламы (рекламодатель, ИНН, erid)
- `UTM_PARAMS` — метки, которые добавятся ко всем ссылкам на выпуски, например `utm_source=landing&utm_medium=web&utm_campaign=smart`
- `FAQ_PENDING` — ответы на вопросы, которые ждут подтверждения банка

Официальный логотип положите в `assets/logo.svg`.

Шрифт — Inter (лицензия SIL OFL, `assets/fonts/Inter-OFL.txt`), подключён из репозитория без Google Fonts. Это свободная замена фирменному шрифту Т‑Банка.
